它是怎么工作的

  1. 抓取：拉取 5 个 RSS / JSON Feed（近 48 小时新内容）
  2. 去重：按链接去重，按发布时间倒序，取前 30 条
  3. 摘要：8 条一批交给大模型，输出标题 / 摘要 / 要点 / 分类
  4. 成稿：主编模型合成 4-6 段编者按、今日要点、分类统计
  5. 分发：写 Markdown+JSON → 邮件 → Telegram → 部署本站

模型策略：Groq（主）→ Gemini（备），任一供应商日额度耗尽立即切换，绝不空等。

我要自己部署一份

  1. Fork 或新建仓库，把本仓库的 config.yaml 拿过来
  2. 改 config.yaml 的 sources.rss 换成你关注的信息源
  3. 仓库 Settings → Secrets and variables → Actions 添加： GROQ_API_KEY（必填）、GEMINI_API_KEY（选填备用）、 SMTP_HOST/PORT/USERNAME/PASSWORD、MAIL_FROM_EMAIL、 DAYBRIEF_RECIPIENTS、TELEGRAM_BOT_TOKEN、TELEGRAM_CHAT_ID
  4. Settings → Pages → Source 选 GitHub Actions
  5. Actions → AI Daily Brief → Run workflow，跑一次即可

定时任务写在 .github/workflows/ai-daily-brief.yml（cron 23:00 UTC = 北京 07:00），改这一行就能换时间。
